# Candidate extract

The accepted architecture uses a MAX17048 fuel gauge supplied from the battery
and a 0.1 µF VDD bypass capacitor. The exercise focuses only on the relative
placement of U12 and C106 in the native PCB extract. Other features are omitted,
so electrical routing, assembly and full-board clearance require a separate
integration step. Keep the selected part values and the rest of the project
unchanged.
