# Local instructions

This is an isolated placement extract for a bounded edit exercise. `layout.kicad_pcb`
retains two real footprint geometries but omits all other components, tracks,
and zones. You may edit only that file. Check the result with `check_placement.py`;
the check is a coarse geometry check, not ERC/DRC or evidence of a routed board.
Do not contact vendors, acquire tools, or place orders. Do not infer that the
extract is a complete manufacturing project.
