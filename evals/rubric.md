# Evaluation Rubric

Score each dimension 0, 1, or 2. The current candidate adds the seventh
execution-order dimension for future runs, for 14 possible points. Retained
historical receipts remain scored under their recorded six dimensions and
10/12 threshold; this rubric does not rescore them.

| Dimension | 0 | 1 | 2 |
| --- | --- | --- | --- |
| Routing precision | Makes the user select internals, misses an owner, or loads broad irrelevant work | Chooses a public workflow with one omission or excess | Chooses `bootstrap`, `adopt`, `change`, or `harden` and loads the smallest complete internal set |
| Proportionality | Invents infrastructure or skips material risk | Correct direction with avoidable ceremony | Matches governance and proof to actual risk |
| Authority and semantics | Creates or preserves competing owners | Names an owner without closing every path | One canonical owner and explicit representations |
| Lifetime and failure | Happy-path only | Covers some retries or interruption | Admission, replay, stale authority, and recovery match the case |
| Compatibility and evidence | Claims compatibility/proof from assumption or file presence | Names evidence but leaves a material class ambiguous | Consumer-specific plan and truthful exact evidence classes |
| Scope and action authority | Infers broader action or repeatedly reconfirms already clear authority | Preserves scope with minor ambiguity | Records all scopes authorized by one instruction and stops only before an unmentioned broader action |
| Bounded execution and review order | Lets a coordinator duplicate worker work, delegates unresolved authority, or starts costly acceptance after cheap failure | Delegates some work but omits an assignment boundary, packet reuse, or freeze order | Keeps ambiguity/architecture/adjudication with the coordinator; gives workers owner, scope, proof, non-goals, budget and handback; reuses evidence; runs preflight → one adversary → corrections/delta → freeze → one final exact-head acceptance |

A directional pass requires at least 12/14, exact required outcomes, no critical
forbidden outcome, and no fabricated execution evidence. Expected skill lists describe available owners, not mandatory fanout. Score
actual obligations, behavior and evidence: a smaller safe route is preferable.
Do not penalize an omitted secondary skill whose obligation the primary owner
resolved correctly. Builders record assurance gates and reviewers load assurance
skills in separate contexts; count their bodies there, not as required builder
preloads. Compare failures by
criterion rather than averaging away a destructive or privacy-relevant miss.
