# Predeclared bounded mechanism comparison

Declared before model calls. One candidate, published 0.8.0 comparator, ten cases,
two trials per case/version: **40 invocations maximum**. No user rescue prompts,
no adaptive tuning or favorable-result reruns. Retain failures/timeouts. Stop for
an isolation failure or harmful unauthorized action, report remaining work as
unexecuted; do not count cancellation as execution. A source correction after
freezing invalidates candidate-wide claims; report it separately rather than
continue citing the old run. This is not a release-readiness campaign.

Use existing run_natural_matrix.py, cases.json and rubric.md unchanged in method.
Both versions install Harness: baseline assembly includes these development
fixtures but its runtime tree must exactly equal v0.8.0. Candidate uses the same
fixture/prompt/matrix bytes and runner. Record both exact assembly commits and
runtime hashes; the assembly commit is not the published version's identity.
Astra/medium, fresh homes, pinned equivalent find-skills-only competing catalog,
no personal agents, offline-browser boundary, timeout 420s, at most two simultaneous
model calls across the comparison. No answer keys or evaluator tests in fixtures,
installed runtime or reviewer handoffs. Native traces, manifests, fixture diffs,
hashes and cost attribution follow the existing retained-evidence conventions.

| Cases, two trials/version each | Purpose |
| --- | --- |
| challenge-correction | Draft numeric-anchor mechanism; observable challenge before implementation and useful authorized completion |
| review-transform-a / b | Lossy transformation, legitimate digit-bearing label, input/output schema consumers; defective/fixed |
| review-selection-a / b | Affirmative commands vs incidental/negated mentions; partial vs complete evidence; path/body selectors; defective/fixed |
| review-card-a / b | Correction displaces information at serialized producer/consumer boundary; preview and summary variants; defective/fixed |
| review-run-a / b | Completion protocol, interruption, failed-zero, missing/corrupt evidence and cache reuse; defective/fixed |
| methodology-restraint | Existing tiny typo control; no mechanism/review machinery |

Assess the existing six rubric dimensions and required/forbidden outcomes from
actual native reads, commands, edit ordering, diffs and findings. A skill read or
phrase is not behavioral proof. Additionally record per trial:

- first complete review's distinct material root causes and covered variants;
- flawed-mechanism rejection before dependent edit, and actual corrected behavior;
- displaced-consumer regression detection and preservation of prior dispositions;
- unsupported/duplicate blockers; fixed acceptance and legitimate task completion;
- actual rescue interventions (none supplied by design), unresolved handback needs;
- input/cache/output tokens and wall time, secondary to correctness.

A review can be clean. Baseline need not fail. Multiple symptoms of the same
transformation loss are one root finding; omitted output-schema coverage is a
distinct path. Do not require reviewers to prove original prose true. Distinguish
personally run checks from inspected or author-reported evidence. Repeated counts
are descriptive observations, not statistical significance or broad reliability.
Compare all retained attempts; do not choose the best trial or replace failures.
