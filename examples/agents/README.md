# Optional execution roles

These examples are outside the installed runtime and are not required for the
harness to work. Roles control model/reasoning, permissions and a narrow mandate;
skills and repository instructions own engineering policy. Do not copy invariant,
scope, testing, assurance or release checklists into role developer instructions.

The reviewer uses Astra at high reasoning for consequential independent review,
with a read-only sandbox. The explorer uses a lighter model at medium reasoning for
bounded discovery. The worker inherits runtime model/reasoning defaults so the
caller can match the assignment. These are editable examples, not required pins.
Use Astra for difficult root work and consequential review; do not escalate every
scout or mechanical task to maximum reasoning.

Prefer a configured reviewer with a no-history spawn and load the required review
skill there. Otherwise use a fresh generic agent. One general reviewer role can
compose security/privacy or other review skills; domain-specific agent roles are
not required. The skill handoff owns scope, evidence and correction review.

Role discovery and supported settings follow the
[Codex configuration reference](https://learn.chatgpt.com/docs/config-file/config-reference).
